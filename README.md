# REACH Summerstrand: Pre-Bible Study Games

An interactive game board for the short video segment we film before Bible study. It runs in any browser, with no installs or logins.

## The five-week rotation

1. **Bible or Not?** Real verse, hymn lyric, or just a popular saying?
2. **True or False** Quick statements about Bible stories.
3. **Finish the Verse** Read the start of a verse, they finish it.
4. **Who Said It?** Match a famous line to the right Bible figure.
5. **Emoji Bible** Guess the Bible story from emojis.

The home screen highlights this week's segment automatically.

## Features

- 16 to 18 questions per segment, each with the answer, a short explanation and the NIV reference
- Tap (or press 1 to 4) to lock in the member's answer, then reveal it
- Countdown timer (10, 15, 20 or 30 seconds) with sound
- Scoreboard for the people on camera
- Shuffle mode, full screen mode, and light or dark theme

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| Space | Reveal answer |
| → / ← | Next / previous question |
| 1 to 4 | Lock in an answer |
| T | Start or pause the timer |
| S | Open the scoreboard |
| F | Full screen |
| Esc | Back to all games |

## Putting it online with GitHub Pages

1. Go to **Settings > Pages** in this repo.
2. Under **Branch**, choose `main` and `/ (root)`, then press **Save**.
3. After a minute the site will be live at `https://khotsosefako9-lang.github.io/Bible-Study/`.

## Adding or editing questions

All questions live in the `SEGMENTS` list near the bottom of `index.html`. Copy an existing question, change the text, and keep the same fields. Please have the pastor check new questions before filming.
